  - pitchA 채택, 숙이면 양수로 확정(`Feedinggame` 70행). pitchB·`Pitchprobe`는 잔재 → 5-5에서 정리
- [x] 10-1 다섯 동작 상태 머신 + 하단 5단계 표시줄 (2026-09-09)

- [~] 10-2 판정 연결 — 벌림 → 다뭄 → 숨참기 안내 1.3초 → 턱당김(**아래만**) → 기침 · 완충 · 6초 도움말 ( )
  - 판정·완충은 완성. ★턱 각도 12°가 맞음: 문헌(Ra et al., Dysphagia 2014)은 chin tuck 효과를 보려면 최소 17.5°의 경부 굴곡이 필요하다고 보고. 12°는 게임 난이도를 고려해 임상 기준보다 관대하게 잡은 값이며, 10°로 낮추지 말 것. 남은 것: **HintText 오브젝트가 씬에서 비활성이라 6초 도움말이 실제로 안 뜸** → 켜기
- [x] 10-3 기준 pitch를 동작 시키기 **전에** 잡기 · 고개 젖힘은 인정 안 됨 확인 (2026-09-09)
