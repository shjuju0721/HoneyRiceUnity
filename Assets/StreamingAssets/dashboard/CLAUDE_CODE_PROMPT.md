# 꿀떡꿀떡 웹 대시보드 제작 지시

## 만들 것

Unity 재활 게임 「꿀떡꿀떡」의 기록 대시보드를 **오프라인 정적 웹페이지**로 만들어 주세요.
게임에서 "내 기록 보기"를 누르면 브라우저로 열리는 한 페이지입니다.

**만들 위치**: `Assets/StreamingAssets/dashboard/`

```
Assets/StreamingAssets/dashboard/
    index.html
    style.css
    app.js
    chart.min.js      (필요하면. 아래 "차트 라이브러리" 참고)
```

⚠ `data.js`는 만들지 마세요. Unity가 실행할 때 자동으로 생성해 같은 폴더에 넣습니다.
다만 개발 중 미리보기를 위해 **`data.sample.js`**(가짜 데이터)를 만들어 두고,
`index.html`에서는 `data.js`를 불러오되 없으면 샘플로 대체하는 식으로 확인하세요.
최종 `index.html`은 반드시 `<script src="data.js"></script>`를 씁니다.

---

## ⚠ 제약 조건 (반드시 지킬 것)

1. **`file://`로 열립니다.** 로컬 서버가 없습니다.
   - `fetch()`·`XMLHttpRequest`로 파일을 읽으면 CORS로 막힙니다. **쓰지 마세요.**
   - ES 모듈(`type="module"`, `import`)도 `file://`에서 막힙니다. **일반 `<script>`만** 쓰세요.
2. **인터넷 없이 동작해야 합니다.** CDN 링크 금지. 웹폰트 로드 금지.
   차트 라이브러리를 쓴다면 파일을 폴더 안에 직접 넣으세요.
3. **이모지 금지.** 아이콘이 필요하면 인라인 SVG로 그리세요.
4. **판정·진단 표현 절대 금지.** 이 소프트웨어는 의료기기가 아닙니다.
   - 금지: "좋아졌어요", "나빠졌어요", "정상", "이상", "주의", "경고", "개선률", 화살표 증감 표시, 빨간 경고색
   - 허용: 숫자, 선, 날짜, "N판 했어요", "N일 했어요"
   - 해석은 전문가의 몫입니다. 데이터만 보여주세요.
5. **대상이 고령자입니다.**
   - 본문 글자 최소 18px, 카드 제목 22px 이상, 큰 숫자 40px 이상
   - 정보 밀도를 낮게. 한 카드에 한 가지만
   - 애니메이션은 은은하게. 깜빡임·갑작스러운 번쩍임 금지
6. **한국어.** 모든 문구는 쉬운 한국어로. 전문용어 대신 일상어를 쓰세요
   (예: "구순 폐쇄" ❌ → "입술 다물기" ⭕).

## 데이터 구조

Unity가 만드는 `data.js`는 이렇게 생겼습니다.

```javascript
window.DASHBOARD_DATA = {
  "nickname": "신현주",
  "generatedAt": "2026-09-11 21:30",
  "totalPlays": 31,
  "records": [
    {
      "day": "2026-09-11",           // yyyy-MM-dd
      "playedAt": "2026-09-11 16:41:51",
      "stage": 1,                     // 1~10
      "reps": 21,                     // 반복 횟수
      "maxEffort": 0.7684,            // 그 판에서 낸 최대 동작값
      "hasEffort": true,              // false면 maxEffort는 의미 없음
      "side": ""                      // "left"/"right"(7번), "cheek"/"lip"(4번), 나머지 ""
    }
  ]
};
```

### 스테이지 정보

| 번호 | 이름 | 운동 | reps의 의미 | maxEffort의 의미 | 값 범위(참고) |
|---|---|---|---|---|---|
| 1 | 계단 오르기 | 입 크게 벌리기 | 오른 계단 수 | 입 벌린 크기 | 0~1 |
| 2 | 줄다리기 | 입술 다물기 | 완료 세트 | 입술 다문 힘 | 0~0.4 |
| 3 | 하트 | 입술 오므리기 | 하트 수 | 입술 오므린 크기 | 0~0.5 |
| 4 | 펭귄 슬라이딩 | 볼 부풀리기 | 발사 횟수 | 볼/입술 크기 | 볼 0~0.03 · 입술 0~0.4 |
| 5 | 미소 사진관 | 미소 짓기 | 사진 수 | 미소 크기 | 0~1 |
| 6 | 개구리 | 혀 내밀기 | 잡은 파리 수 | 혀 내민 크기 | 0~1 |
| 7 | 젤리 분류 | 혀 좌우 | 좌·우 각각 | 좌·우 뻗은 크기 | 0~0.3 |
| 8 | 러너 | 혀 위아래 | 통과 수 | **없음** | — |
| 9 | 민들레 | 기침하기 | 기침 수 | 기침 세기 | 0~100 |
| 10 | 떠먹이기 | 삼킴 순서 연습 | 완료 술 수 | **없음** | — |

**⚠ 반드시 지킬 데이터 규칙**

- **스테이지 4와 7은 한 판에 두 줄**이 저장됩니다(`side`가 다름). 판 수를 셀 때 2배가 되지 않게 `stage + "|" + playedAt`으로 묶으세요.
- **스테이지 8·10은 `hasEffort: false`** — `maxEffort`가 없습니다. 이 둘은 **판 수**로만 보여주세요. 절대 0을 값으로 그리지 마세요.
- **같은 날 여러 판을 하면 그날의 최고값 하나만** 씁니다. 평균 금지(컨디션 나쁜 판이 추이를 흐립니다).
- **값의 크기가 스테이지마다 크게 다릅니다**(볼 0.0159 ~ 기침 88). 소수 둘째 자리로 고정 반올림하면 볼 값이 전부 0.02로 뭉개집니다. **유효숫자 3자리**로 표시하세요.
- 기록이 없는 스테이지가 있을 수 있습니다. 빈 카드는 "아직 기록이 없어요"로.

## 화면 구성

한 페이지, 세로 스크롤. 위에서부터:

### 헤더
```
꿀떡꿀떡 · OOO 님의 기록
2026-09-11 21:30 기준
```

### 요약 숫자 카드 3개 (가로 나란히)
1. **이번 주 판 수** — 최근 7일간 한 판 수
2. **꾸준히 한 날** — 기록이 있는 날의 총 수 ("N일 했어요")
3. **가장 많이 한 운동** — 판 수가 제일 많은 스테이지 이름

각 카드는 큰 숫자(48px 이상) + 작은 설명 한 줄.

### 성장 카드 (★가장 중요, 크게)
전체 판 수(`totalPlays`)에 따라 식물이 자랍니다. **인라인 SVG로 직접 그리세요.**

| 단계 | 누적 판 수 | 모습 |
|---|---|---|
| 1 | 0~4 | 흙과 씨앗 |
| 2 | 5~14 | 새싹 (떡잎 두 장) |
| 3 | 15~29 | 잎이 여럿인 풀 |
| 4 | 30~49 | 작은 나무 |
| 5 | 50~79 | 큰 나무 |
| 6 | 80~ | 열매 달린 나무 |

- 카드 안에 단계 이름("작은 나무가 됐어요")과 **"다음 단계까지 N판"** 한 줄
- ⚠ **단계는 절대 내려가지 않습니다.** 누적 판 수 기준이라 자연히 그렇습니다. 최근 활동으로 계산하지 마세요 — 쉬었다고 나무가 새싹이 되면 "못했다"는 신호가 되어 원칙에 어긋납니다.
- 최고 단계(6)에 도달하면 "다음 단계까지" 줄 대신 격려 문구 한 줄
- 화분이나 땅에 심긴 모습으로, 게임 캐릭터 톤에 맞게 둥글고 부드럽게

### 회복 추이 카드 (넓게)
- 가로 = 날짜, 세로 = 그날 최고값인 선그래프
- **여러 동작을 한 그래프에 올려야 하는데 값의 크기가 다릅니다.** 스테이지를 고르는 탭이나 체크박스를 두어 한 번에 1~3개만 겹쳐 보이게 하세요. 기본값은 스테이지 1.
- 스테이지 4는 볼·입술 두 선, 7은 왼쪽·오른쪽 두 선
- 그날 기록이 없으면 선을 끊으세요(0으로 잇지 마세요)

### 좌우 균형 카드
- 스테이지 7의 왼쪽·오른쪽을 나란히 비교
- 두 선 그래프 + 최근 값 숫자 두 개
- ⚠ **카드 맨 위에 안내 한 줄 고정**: "왼쪽·오른쪽 기록을 그대로 보여드려요. 차이의 의미는 선생님과 상담해 주세요."
- 차이를 %로 표시해도 되지만 "비대칭", "이상" 같은 말은 쓰지 마세요

### 활동 캘린더 카드
- 월 달력 + 이전·다음 달 버튼
- 칸 색 짙기 = 그날 판 수(1·2·3·4판 이상 네 단계)
- 기록이 있는 날만 눌리고, 누르면 그날 한 게임 목록이 아래에 뜸

### 게임별 판 수 카드
- 스테이지 10개의 판 수 가로 막대
- 한 번도 안 한 게임은 회색 빈 막대로 표시(있다는 걸 알 수 있게)

## 색 팔레트 (게임 화면에서 따온 값)

게임은 크림·파스텔 톤이고 배경에 연분홍·연보라 세로 줄무늬가 있습니다. 대시보드도 같은 분위기로.

```css
--bg:        #FBEEE6;   /* 전체 배경 (따뜻한 크림) */
--card:      #FFFFFF;   /* 카드 바탕 */
--card-tint: #F4F8F7;   /* 강조 카드 바탕 (아주 연한 청록빛 흰색) */
--ink:       #4A3B33;   /* 본문 글자 (진한 갈색) */
--ink-soft:  #8A7A70;   /* 보조 글자 */
--line:      #E6D9CF;   /* 카드 테두리·구분선 */

--coral:     #E87B5E;   /* 포인트 1 — 첫 번째 선, 강조 숫자 */
--teal:      #8FBFD0;   /* 포인트 2 — 두 번째 선 */
--pink:      #F2C4CE;   /* 보조 — 캘린더 옅은 칸 */
--lilac:     #D9CCE3;   /* 보조 */
--leaf:      #7FB069;   /* 성장 카드 잎 */
--leaf-dark: #5E8C4F;   /* 성장 카드 줄기·진한 잎 */
--fruit:     #E86A5E;   /* 성장 카드 열매 */
--soil:      #A8836B;   /* 성장 카드 흙 */
```

- 카드는 흰 바탕 + 둥근 모서리(16px) + 아주 연한 그림자
- 빨강 계열은 경고가 아니라 포인트로만 쓰세요
- 글꼴은 시스템 글꼴 스택으로(웹폰트 금지):
  `font-family: "Malgun Gothic", "맑은 고딕", "Apple SD Gothic Neo", sans-serif;`

## 차트 라이브러리

두 가지 중 선택하세요.

- **(추천) 직접 SVG로 그리기** — 선 몇 개와 막대라 어렵지 않고, 파일이 가벼우며 색·글자 크기를 팔레트에 정확히 맞출 수 있습니다. 라이브러리 버전 문제도 없습니다.
- **Chart.js** — 쓴다면 `chart.min.js`를 폴더 안에 직접 넣고 `<script src="chart.min.js">`로 불러오세요. CDN 금지.

어느 쪽이든 **툴팁·범례 글자를 16px 이상**으로 키우세요. 기본값은 어르신께 너무 작습니다.

## 반응형

- 노트북(1280px 이상): 카드 2열
- 태블릿 세로(768~1279px): 카드 1열, 요약 카드 3개는 가로 유지
- 그 아래: 전부 1열

## 확인 사항

만든 뒤 `index.html`을 **브라우저에서 파일 그대로 열어** 확인하세요(로컬 서버 쓰지 말고).
콘솔에 CORS 오류가 없고, 데이터가 없을 때도 화면이 깨지지 않아야 합니다.
